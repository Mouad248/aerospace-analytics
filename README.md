# Aerospace Analytics

Two projects using public benchmark data to study airline disruptions and
aircraft-engine degradation.

## Projects

- [Airline Disruption Analytics](airline-disruption-analytics/README.md)
- [Engine Prognostics](engine-prognostics/README.md)

Open each project README for setup, run instructions, data provenance,
limitations, and source terms. The engine-prognostics source catalogue does
not specify a dataset license; the raw archive is excluded. Preserve
attribution and check the publisher terms before redistributing source data.
No collection-wide code or data license is provided.
